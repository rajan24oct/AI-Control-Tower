After publishing
  1. An external agent: set its credential in the platform's environment, then Sync card on its page to read the skills it offers.
  2. Approve it (a2a.approve). An unapproved agent does not exist for other agents.
  3. Review each skill. A skill is asked for only once it is enabled, and goes back to review if its description changes.
  4. Grant contracts to the agents that may send it work, if it is restricted.
Mailbox or endpoint

An agent with no A2A endpoint of its own takes its work from the gateway's mailbox: it collects tasks from /api/v1/a2a-gateway/inbox/<agent>/ and answers each one. The gateway never calls into it.

An agent that serves A2A is reached at its endpoint. The gateway sends there, not to whatever URL the agent's card names.
