After registering
  1. Set the credential in the platform's environment under the variable you name here.
  2. Health check on its page.
  3. Approve it (mcp.approve). An unapproved server is invisible to every agent.
  4. Sync tools. New tools arrive awaiting review; enable each one deliberately.
  5. Grant agents access, if the server is restricted.
Why a prefix

An agent sees every permitted tool from every server through one endpoint, /api/v1/mcp/<agent>/, so each tool is named <prefix>__<tool>. A tool whose definition changes upstream goes back to review on its own.
