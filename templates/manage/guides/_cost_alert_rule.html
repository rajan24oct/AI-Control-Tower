Rules and budgets
  • A budget watches a period's total. A rule watches a rolling window — the last hour, day or week — so a runaway agent is caught within the hour.
  • Spend increase compares the window with the average of the four windows before it: 100 means "twice the usual".
  • Average cost per run catches a prompt or model change that made every call dearer.
  • Spend on failed runs is money with nothing to show for it.
Noise control

A minimum spend keeps quiet hours from tripping percentage rules; the quiet period stops one incident sending an alert every 15 minutes.

Rules count AI runtime spend. Copilot seats are watched by budgets with Developer tools as the cost source.
