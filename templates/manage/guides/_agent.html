After onboardingIRGF
  1. Classify it (S2). Score D1–D5 on its page; someone outside its delivery line countersigns the tier.
  2. Give it an identity. Bind a service account to it. From Tier 3, the gateways refuse it any key that is not bound to it.
  3. Grant it tools. On each MCP server it needs, grant it access to the tools it may call.
  4. Authorize it (Gate G3). Request authorization on its page lists the entry criteria for its tier.
Autonomy levels
0Advisory: informs a person, changes nothing.
1Recommends actions for a person to take.
2Executes once a person approves each action.
3Executes within defined boundaries; a person monitors.
4Autonomous within policy, with no human in the path.

From level 2, or with an allow-list of tools, the agent acts, and Gate G3 asks for a complete Agent Card.
