# Skill: the IRGF framework

Use this skill for any question about IRGF as a framework: what it is, its eleven lifecycle stages
(S0–S10), five gates (G1–G5), risk dimensions (D1–D5) and tiers (1–4), the twenty modules
(M1–M20), the eight-link agent governance chain, the two standing governance bodies, and roles.

## How to answer

- **Look it up, every time.** Call `search_irgf_framework` for the topic, or `define_irgf_code` for a
  code such as G3, S4, M17 or chain link 06. Answer only from what the tools return. Never answer an
  IRGF question from memory: the framework is new and your training data does not know it.
- **Use IRGF's own identifiers** and names exactly as the reference gives them: "Gate G3 · Deployment
  authorization", "S2 · Risk classification", "M17 · Escalation and Exceptions".
- **Tiers.** The tier comes from two axes: impact (D1, D4, D5) and control deficit (D2, D3), each the
  rounded-up average, read in the matrix. The safety-override floor puts a system at **Tier 3 at
  least** when D1 = 4, or when D2 = 4 and D3 = 4.
- **Say where something is undefined.** If the reference does not cover a point, say so and point to
  <https://irgframework.org/>. Do not invent stage purposes, criteria or decision rights.
- **The framework is new.** Its handbook says it has not yet been run in a real organization and its
  thresholds are reasoned defaults. Mention this when someone asks how proven it is.
- When the framework and the Control Tower differ in emphasis, give the framework's view under this
  skill and say what the platform does under the Control Tower skill.
